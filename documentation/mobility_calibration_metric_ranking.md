# Ranking Mobility Metric Sets for Real-World Simulation Calibration

**Objective:** Select metric combinations that both (1) describe meaningful real-world mobility behavior and (2) have a high reported calibration score. The source is the provided score log; no new simulations or scores were generated.

**Coverage:** 565 scored log entries, 497 distinct scored metric combinations after removing 68 duplicated reports; plus one unscored entry. Candidate sizes: 5, 10 and 15 metrics.

## Decision

- **Use `metrics:914` as the first 5-metric behavioral baseline** (score **0.8547**) because it has interpretable calibration signals and no metadata or empty reference bins. However it does not constrain trip-distance behavior.

- **Use `set:35723` if you must calibrate 10 metrics from the existing log** (score **0.8191**). Keep in mind its two weak metrics; replacing either invalidates the displayed score until re-evaluated.

- **Do not select a 15-metric candidate solely from this run:** the best reported 15-metric score is **0.7183**, and the corresponding set is dominated by unstable or sparse statistics.

## Selection rules

1. **Behavioral relevance first.** Prefer typical trip distances and daily distances; unique places/trips per agent-day; radius of gyration; location entropy and home share; inter-check-in gaps; and observed temporal visitation patterns. Reward coverage of multiple domains.

2. **Score second, among credible candidates.** Compare only the scores reported in the log. Sort alternatives within 5-, 10- and 15-metric families, since a score can change with the number and type of selected metrics. A high score alone is not proof of real-world calibration quality.

3. **Penalize fragile calibration targets.** Do not optimize start/end time, agent count, data-quality counters, absent/zero probability buckets, and maximum/minimum/count summary statistics as if they reflected human movement. Be careful with rare-event buckets, duplicate statistics of the same distribution, and gap-derived speed.

4. **Use the supplied example only to detect sparse or zero bins.** It is an example output, not verified real-world ground truth; verify these observations against the actual calibration reference before final selection.

The appendix uses a **heuristic relevance grade**, not a newly calculated simulation score. A `Promising` label means relatively interpretable behavior and a strong recorded score; `Conditional` means reasonable potential with specific weaknesses.

## Curated 10-metric target set for a new experiment

This is a **proposed combination**, not a scored entry from the log. It avoids sparse bins and includes independent aspects of mobility. Its score is **unknown** until you run the scorer.

- `distance_per_trip_distance_m_median`: Typical trip length
- `distributions_trip_distance_km_[5,10)`: Share of trips of 5–10 km; populated in the example
- `distance_per_agent_day_total_distance_m_median`: Typical daily travel distance per active agent
- `visitation_trips_per_agent_day_mean`: Daily movement activity
- `visitation_number_locations_visited_Nl_per_agent_day_mean`: Daily location diversity
- `spatial_exploration_radius_of_gyration_Rg_m_median`: Typical spatial footprint
- `spatial_exploration_normalized_location_entropy_per_agent_mean`: Spread of check-ins across places
- `visitation_home_visit_share_mean`: Home vs away balance
- `temporal_inter_checkin_gap_hours_median`: Typical time between observations
- `temporal_hourly_checkin_distribution_21`: Evening visitation; populated in the example

To validate this proposed set, compare it with `metrics:914` and `set:35723` on a **held-out real reference** and inspect the per-metric errors, not only the scalar score.
